## プロファイル

<LinkPreview id="https://learn.microsoft.com/ja-jp/powershell/module/microsoft.powershell.core/about/about_profiles" />

> PowerShell プロファイルは、PowerShell の起動時に実行されるスクリプトです。 プロファイルをスタートアップ スクリプトとして使用して、環境をカスタマイズできます。

> PowerShell では、ユーザーと PowerShell ホストを対象とする複数のプロファイル ファイルがサポートされています。

> $PROFILE 変数の現在の値を表示するには、次のように入力します。
>
> ```powershell
> $PROFILE | Select-Object *
> ```

## 設定例

```powershell
Import-Module posh-git
$GitPromptSettings.EnableFileStatus = $false
$GitPromptSettings.EnablePromptStatus = $false
Invoke-Expression (&starship init powershell)
Invoke-Expression (& { (zoxide init powershell | Out-String) })
fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression
```
