> ## 手順 2: Rust をインストールする
>
> 公式の Rust インストーラー rustupは、コンパイラ、Cargo、将来の更新プログラムなど、すべてを処理します。
>
> ### WinGet
>
> ```powershell
> winget install Rustlang.Rustup
> ```
>
> ### rustup.rs
>
> [rustup.rs](https://rustup.rs/) からインストーラーをダウンロードして実行します。 MSVC ツールチェーンをインストールする場合は既定値をそのまま使用します。これは Windows 開発に推奨されます。
