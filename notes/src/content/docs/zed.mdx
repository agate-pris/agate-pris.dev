## その他

- 折り返しの切り替えはデフォルトで `ctrl-k` `ctrl-z` / `ctrl-k` `z` に割り当てられている。これは AMD Software: Adrenalin Edition とコンフリクトしないため Visual Studio Code の `alt-z` よりも、むしろ都合が良い。
